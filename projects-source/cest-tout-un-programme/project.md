## Short description

Lors de ma deuxième année de DSAA, j'ai conçu un mémoire qui traite de l'implication des outils numériques dans le travail de design. Mon appétence pour le code m’a donc amené à me questionner sur les languages informatiques/outils numériques que nous utilisons dans notre pratique de design.

## Content

**Sujet: **En quoi la compréhension des outils numériques enrichit il notre pratique du design graphique ? Pourquoi les logiciels déplacent-ils les enjeux des designers ? Est-ce que se baser sur la contrainte technique est une bonne méthodologie de design ?
