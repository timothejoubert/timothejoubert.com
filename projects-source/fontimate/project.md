## Short description

Conception d'une interface web permettant d'animer de la typographie variable et d'une landing page présentant l'outil en ligne.

## Content

Dans le cadre de mon Master 2, nous avions comme objectif de réaliser un outil utile pour les designers web. Il permet de tester différents types d'animations à partir d'une typographie variable et de récupérer le code pour l'intégrer dans un site. Je souhaitais proposer le plus d'options possibles pour montrer le champ des possible. J'ai donc été confronté à de nombreux problèmes d'UX. Il a donc fallu faire comprendre visuellement et de manière synthétique la diversité des paramètres. J'ai pensé et conçu l'interface web, développé le site et l'outil web avec Vue (langage que je n'avais jamais utilisé) en 1 mois. Même si le site final n'est pas tout à fait abouti et manque d'intuitivité, je suis plutôt satisfaite de ma réalisation dans le temps imparti.
